Ferramenta · Automação

Digitação Cadenciada

Ferramenta universal que digita textos automaticamente em qualquer campo do navegador.

Ativar Digitação Cadenciada

Arraste esse botão para a barra de favoritos.

Depois, cole no favorito (instruções abaixo).

💻 Como usar (desktop)

  1. Se a barra de favoritos não está visível, aperta Ctrl+Shift+B (ou Cmd+Shift+B no Mac)
  2. Arrasta o botão Ativar Digitação Cadenciada para a barra de favoritos
  3. Abra o site onde deseja digitar o texto
  4. Clique no favorito que você salvou
  5. Cole o texto no painel, ajuste a velocidade e clique no campo onde o texto será digitado

📱 Como usar (celular)

  1. Clique em Copiar bookmarklet (botão acima)
  2. Abra o Chrome — toque nos 3 pontinhos — Favoritos
  3. Toque em qualquer favorito e segure — Editar
  4. Apaga a URL e cola o código do bookmarklet
  5. Salva
  6. Quando quiser usar: abra o site onde vai digitar e toque no favorito que você salvou
⚠ Só funciona na página onde você está. Alguns sites muito seguros podem bloquear.
