Instalação para Computador

Siga os passos abaixo para adicionar a ferramenta à sua barra de favoritos:

  1. Clique e arraste o botão azul abaixo até a sua barra de favoritos.
  2. Em qualquer site, clique no favorito para abrir o painel.
Arrastar para Favoritos

Não vê a barra? Pressione Ctrl+Shift+B (ou Cmd+Shift+B no Mac).

Instalação para Celular

Como os navegadores móveis não suportam arrastar, siga estes passos:

  1. Toque no botão Copiar Código abaixo.
  2. No menu do navegador, toque em Adicionar aos Favoritos.
  3. Edite o favorito e cole o código no campo de endereço (URL).
